# 💻 Desu Computer Solution

A modern full-stack computer service management system built to streamline customer management, repair tracking, employee administration, and service order processing for computer repair and IT service businesses.

---

## 📌 Overview

Desu Computer Solution is a web-based management platform designed to simplify the daily operations of a computer repair shop. It enables staff to efficiently manage customers, devices, repair services, employees, and service orders through an intuitive dashboard.

---

## ✨ Features

* 🔐 Secure Employee Authentication
* 👨‍💼 Employee Management
* 👥 Customer Management
* 💻 Device Registration & Management
* 🛠️ Repair & Service Order Management
* 📊 Administrative Dashboard
* 🔍 Search and Filter Functionality
* 📱 Fully Responsive Design
* ⚡ Fast REST API Integration
* 🗄️ MySQL Relational Database

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/DEVA-BIR/computer-solution.git
```

### 2. Go to the Project Folder

```bash
cd computer-solution
```

### 3. Install Dependencies

Frontend

```bash
npm install
```

Backend

```bash
npm install
```



### 5. Start the Project

Frontend

```bash
npm run dev
```

Backend

```bash
npm start
```
